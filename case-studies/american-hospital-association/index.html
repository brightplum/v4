American Hospital Association

Rebranding the Coding Clinic Advisor site and making it more approachable — while giving editors real control over content, membership messaging, and reporting.

The American Hospital Association's Coding Clinic Advisors provide official guidance on coding practices and conventions, helping healthcare professionals accurately code medical diagnoses and procedures. The Coding Clinic, published by the AHA, offers official advice, guidelines, and updates on coding changes — ensuring consistent, accurate documentation across the field.

Visit codingclinicadvisor.com →

Key elements

Website redesign Custom features Editorial tooling

The challenge

The site carried several everyday frustrations that added up. Editors couldn't pin important news to the homepage or filter news by year, making it hard to highlight and organize content. Existing members were shown a "Become a Member" message instead of "Renew Membership," causing confusion. The text editor made it difficult to adjust and format images. And there was no way to export People-page information to CSV.

Pin & filter news

Added a field to pin news articles on the homepage and a sidebar year filter — so editors can highlight what matters and organize the archive.

Membership-aware messaging

A custom module tailors messages by role: members now see the correct "Renew Membership" prompt instead of "Become a Member."

Flexible content editing

New image-formatting options let editors adjust size, alignment, and shape — improving how content is presented across the site.

CSV data export

A custom view enables CSV export from the People page, so administrators can pull the data they need for management and analysis.

The result

Together, these improvements resolved the client's critical challenges — enhancing the user experience, improving content management and presentation, and giving administrators the tools they'd been missing.
